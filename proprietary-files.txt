# MiLiteRT / QNN runtime. The stub APK links against these from its own
# lib/arm64 directory, which only holds symlinks into system_ext/lib64/litert;
# tracking the real files keeps the linker happy and gives the QNN libraries
# a single location.

# The TensorFlow Lite JNI libraries next to the QNN runtime are provided by
# AOSP's external/tensorflow, so they are intentionally not extracted here.


# Blobs shipped by the international firmware but absent from the China dump
# (OS4.0.5.0.XGNCNXM, checked against all nine partitions). The China build
# implements the same functionality with the components named after each
# entry, and those substitutes are listed earlier in this file.
#
# - vendor/bin/hw/vendor.dolby.media.c2-default-service-dax
#       Dolby is a DMS HAL here: vendor.dolby.dms.service
# - vendor/etc/init/vendor.dolby.media.c2-default-service-dax.rc
#       covered by vendor/etc/init/dms-service.rc
# - vendor/etc/vintf/manifest/vendor.dolby.media.c2-default-service-dax.xml
#       covered by vendor/etc/vintf/manifest/dms-service.xml
# - vendor/etc/media_codecs_dolby_audio.xml
#       Dolby decodes through libqcodec2_dolbydecoderfilter.so and the dax
#       configs; the encoder and enhancement filters are not shipped here
# - vendor/lib64/libcodec2_store_dolby.so
#       Dolby codecs via libcodec2_store_mi.so
# - vendor/etc/vintf/manifest/dpm-saidl.xml
#       no equivalent, the data port manager is not used by this build
# - system_ext/lib64/libimscamera_jni.so
#       no equivalent, the China IMS stack has no camera sharing
